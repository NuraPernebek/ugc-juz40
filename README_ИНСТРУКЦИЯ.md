# JUZ40 — UGC аналитика: пошаговая инструкция

Весь процесс: собрали данные скриптом → сделали data.json → закинули на GitHub → сайт обновился сам.

---

## ШАГ 0. Установка (делается ОДИН раз)

Нужен Python 3.10+. Открываете терминал в этой папке и выполняете:

```
pip install -r requirements.txt
playwright install webkit
```

Проверка: `python --version` (если команда не найдена — попробуйте `python3` и `pip3` везде далее).

---

## ШАГ 1. Собрать посты по хэштегу

Для каждого конкурсного хэштега запускаете:

```
python tiktok_scrape.py juz40jurekte
python tiktok_scrape.py juz40online
python tiktok_scrape.py juz40fest26
```
(и так далее по списку ваших хэштегов)

Что происходит:
- Откроется окно браузера со страницей хэштега.
- Если появилась капча — пройдите её мышкой, скрипт подождёт.
- Скрипт сам прокручивает страницу и перехватывает данные.
- В конце появится файл `posts_ИМЯХЭШТЕГА.json`.

Если постов не перехвачено — смените VPN-сервер и запустите ещё раз.

---

## ШАГ 2. Собрать всё в один data.json

```
python make_data.py
```

Скрипт возьмёт ВСЕ файлы `posts_*.json` в папке, уберёт дубликаты,
отфильтрует по конкурсным хэштегам и создаст **data.json**.

Список конкурсных хэштегов меняется в начале файла `make_data.py`
(переменная CONTESTS) — там же, где в tiktok_report.py.

(Необязательно: `python tiktok_report.py` и `python tiktok_analyze.py posts_juz40jurekte.json` —
ваши старые отчёты в консоль, работают как раньше.)

---

## ШАГ 3. Загрузить data.json на GitHub

Первый раз:
1. github.com → New repository → имя например `juz40-data` → Public → Create.
2. Add file → Upload files → перетащите `data.json` → Commit changes.
3. Откройте файл data.json в репозитории → кнопка **Raw** → скопируйте ссылку.
   Она выглядит так:
   `https://raw.githubusercontent.com/ВАШ_ЛОГИН/juz40-data/main/data.json`

Каждое следующее обновление:
1. Откройте data.json в репозитории → иконка карандаша (или Upload files поверх).
2. Вставьте новое содержимое → Commit changes.
3. Сайт подхватит данные через 1–3 минуты (страница сама перепроверяет каждые 5 минут).

---

## ШАГ 4. Поставить сайт на Tilda (ОДИН раз)

1. Откройте `juz40_ugc_analytics.html` в блокноте/редакторе.
2. В самом начале `<script>` найдите строку:

   ```
   var DATA_URL = 'https://raw.githubusercontent.com/NuraPernebek/nurnurnurnur/main/data.json';
   ```

   и замените на ВАШУ Raw-ссылку из Шага 3.
3. В Tilda: добавить блок **T123 «HTML-код»** → вставить содержимое файла ЦЕЛИКОМ
   (от `TILDA START` до `TILDA END`) → Сохранить → Опубликовать.

Чтобы посмотреть сайт локально без Tilda — просто откройте
`juz40_ugc_analytics.html` двойным кликом в браузере.

---

## Итог: рутина обновления (2 минуты)

```
python tiktok_scrape.py juz40jurekte      # по каждому хэштегу
python make_data.py
```
→ заменить data.json на GitHub → готово, сайт обновился.

## Файлы в этой папке

| Файл | Что делает |
|---|---|
| tiktok_scrape.py | собирает посты по хэштегу (ваш скрипт) |
| tiktok_analyze.py | отчёт в консоль по одному хэштегу (ваш скрипт) |
| tiktok_report.py | общий отчёт по всем конкурсам (ваш скрипт) |
| **make_data.py** | НОВОЕ: делает data.json для сайта |
| **juz40_ugc_analytics.html** | НОВОЕ: сайт аналитики для Tilda |
| data_example.json | пример того, как выглядит data.json |
| requirements.txt | зависимости для pip |

## Частые проблемы

- **Сайт пишет «Данные не загрузились»** — проверьте DATA_URL: откройте ссылку
  в браузере, должен показаться JSON. Репозиторий должен быть Public.
- **«posts_*.json не найдены»** — запускайте make_data.py из той же папки,
  где лежат файлы posts.
- **Цифры на сайте старые** — подождите 2–3 минуты после коммита и обновите
  страницу с зажатым Shift (жёсткое обновление).
- **Капча в скрейпере не проходит** — смените VPN-сервер, перезапустите скрипт.
